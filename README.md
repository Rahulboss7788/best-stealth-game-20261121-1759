The Velvet Vault — a top-down museum heist at night. You are Wren, a thief: sneak past the patrolling night guards and their vision cones, hide behind statues and display cases, lift the Star of Halcyon, and reach the green exit unseen.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser. Move with WASD or arrow keys (or click to walk to a spot), P pauses, M mutes.
